# Todo Test Task

Тестовое задание: страница задач с фильтром по приоритету и созданием задачи через модалку.

## 🚀 Запуск

\`\`\`bash
npm install
npm run dev
\`\`\`

Откройте [http://localhost:5173](http://localhost:5173).

## 🛠 Стек

- React 19 + TypeScript
- Vite
- **Без сторонних библиотек** (только React и ReactDOM)

## 💡 Принятые решения

- **`useMemo` для фильтрации** — список не пересчитывается на каждом рендере.
- **`useCallback` для `addTask`** — стабильная ссылка на функцию.
- **`React.memo` для `TaskCard`** — карточка не ререндерится, если пропсы не изменились.
- **`crypto.randomUUID()`** — генерация ID без сторонних библиотек (встроено в браузер).
- **Вынесение логики в хук `useTasks`** — компонент `App` чистый, только рендер.
- **`import type`** — типы импортируются отдельно (требование `verbatimModuleSyntax`).
- **Modal закрывается по `Escape`** и клику вне области.
- **Валидация формы** — заголовок минимум 3 символа.
- **Сброс формы** после создания задачи.
- **`autoFocus`** на первом поле — UX.
